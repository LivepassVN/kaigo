# kaigo プライバシー・倫理（Phase 1）

## 位置づけ

- 本システムは **医療機器ではない**
- 緊急時の本体は **119 番・家族・介護者への連絡**
- Agent プロンプトおよび Ability 応答で上記を明示する

## 声・会話データ

- 会話・思い出は **仏壇 AI 転用** を見据えて保存する（利用開始時に目的と保存期間を説明し同意を得る）
- `user_profile.md` / `user_summary.md` は OpenHome 予約のため **書き込まない**
- 独自名前空間: `kaigo_*.md`, `kaigo_*.json`

## カメラ（Phase 1・任意）

- **オプトイン** — 利用者の同意後に有効化
- 撮影前に **声で告知**（「写真を撮ります」）
- 定期スナップショットは **低頻度・低解像度** を想定（在宅シグナル程度）。人物検出は在宅確認に留め、**顔認識・常時録画は Phase 1 では採用しない**
- 画像は DevKit ローカル優先。家族共有は Phase 2（オプトイン）

## 在宅・応答の簡易検知（任意）

- 長時間無音や通常時間帯の未応答から **声かけのみ** を行う設計があり得る
- **誤検知**（昼寝・外出・テレビ音量など）があり得るため、自動通報や家族通知には使わない（Phase 1）。挙動を変更する場合は README / 利用説明にリスクを明記する

## 家族・見守り（Phase 2）

- 日次サマリー・緊急ログの外部共有は **オプトイン**（`kaigo_family.json` の `enabled` + `consent_given`）
- Webhook 経由で家族リレーサーバへ送信（LINE / Slack 等はサーバ側で転送）
- 画像共有は Phase 2 後半（オプトイン）
- Phase 1 データは DevKit ローカル保存が基本

## データ削除

- 利用終了時は `kaigo_*` ファイルおよびスナップショット画像を削除可能とする
- エクスポート手順は [data-schema.md](data-schema.md) を参照
